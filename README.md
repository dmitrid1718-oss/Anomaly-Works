# Anomaly Works

Minimal single-page laboratory website.

## Hero image

Upload the approved blue horizon image to **assets/horizon.png** in this repository. The page already points to that exact path. Until then, a CSS blue gradient appears as a temporary fallback.

## Publish

Enable GitHub Pages in Settings → Pages → Deploy from branch → main / (root), or import the repository into your preferred static hosting provider. No build step or dependencies.

The **ENTER ↓** anchor smoothly scrolls to the laboratory. Native scrolling works as well. Supports mobile and reduced-motion preferences.
